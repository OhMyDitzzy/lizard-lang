# Vision

**Simple. Strict. Kind.**

Lizard is a language you can start in an hour and still not outgrow.

## Simple
Few concepts, used consistently. The common thing has one obvious way to be
written. Advanced features (types, classes, links, modules) stay out of your way
until you need them, and each one is explained with the concepts you already know.
A new feature earns its place only if it fits the model that is already there.

## Strict
Safety comes from clear limits, not from hidden magic. Memory is predictable and
never pauses the program; ownership cycles are refused with a way out instead of
being quietly collected; third-party code gets no permissions it was not given.
When something is restricted, the restriction is the feature.

## Kind
Every error says what happened, where, and, when there is a clear fix, how to
repair it, often showing the corrected code. Documentation examples are run by the
test suite, so what the docs say is what Lizard does.
